# Flakebuilder GUI

The companion GTK4/Granite frontend provides a Pantheon-style desktop entry point for the existing Flakebuilder workflow. **Configure flake** launches the same selector used by the command-line application, preserving category navigation, package shopping, NUR browsing, review, confirmation, dry-run checks, and `~/generated_flakes` output.

Build it with Meson from this directory. The GUI requires GTK4, Granite 7, Vala, Meson, and Ninja.
